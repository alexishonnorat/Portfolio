Concept

Research without the friction.

One interface from search to understanding — no tab-switching, no manual tracking.

The problem

Academic research means jumping between HAL search, downloading PDFs, skimming 80-page theses to find one relevant section, and manually noting which paper said what. Nothing connects these steps — every tool solves one part and ignores the rest.

The solution

Synapse connects the HAL Science API to a hybrid RAG pipeline and ML modules inside a single Streamlit interface. Search, classify automatically, chat with the document, compare similar theses — without leaving the app. Every answer traces back to the exact chunk it came from.

User workflow

Search, read, ask, compare.

Synapse is designed for researchers who need to move from a broad literature search to focused document understanding.

01

Search HAL

Query the French open archives (HAL Science API) with keyword, domain and methodology filters. Results display enriched metadata — authors, institution, abstract, year — alongside ML-generated classification badges. The search layer handles pagination and delivers structured thesis objects ready for deeper analysis.

02

Classify

A classification pipeline detects domain (8 categories: CS, medicine, economics…), methodology (5 types: experimental, theoretical, applied…) and contribution type for each thesis. Rule-based heuristics run first; a transformer-based mode activates for ambiguous cases, improving accuracy on specialised vocabulary.

03

Chat with PDF

Click any thesis to download and vectorize its PDF. PyMuPDF extracts the text; FAISS indexes the chunks. A side-by-side interface lets you ask questions on the document while seeing the source pages. Every answer cites the specific chunks it was built from.

04

Recommend

OpenAI embeddings represent each document as a semantic vector. The recommendation engine finds the k-nearest neighbours in the FAISS index and surfaces similar theses based on content proximity and metadata alignment — not just keyword overlap.

RAG system

Contextual answers with traceability.

The RAG layer extracts PDF content, chunks it, indexes it in a vector store and answers questions with citations to retrieved passages.

PDF processing

PyMuPDF extracts full document text before a hierarchical chunking strategy splits it into overlapping sections. Chunk size and overlap are tunable. Each chunk is embedded with OpenAI's text-embedding-ada-002 and stored in FAISS. The pipeline handles multi-column layouts, footnotes and reference sections gracefully.

Vector search

FAISS stores and retrieves embeddings at sub-second latency. A configurable top-k retrieval step pulls the most relevant chunks; an optional MMR (Maximal Marginal Relevance) pass diversifies results to avoid redundant context. BM25 reranking adds a lexical signal on top of the semantic one.

Chat experience

LangChain orchestrates the RAG loop: chunks are injected into the context window alongside the user's question, and GPT-4o generates a grounded answer. The PDF viewer scrolls to cited pages. Conversation history is preserved across turns within a session.

ML features

More than retrieval.

Synapse adds classification, multi-level summaries and recommendations to help users navigate a research corpus faster.

Classification

Automatic detection of domain (8 categories: CS, medicine, economics, law…), methodology (5 types: experimental, theoretical, applied, review, mixed) and contribution type. Rule-based heuristics run first for speed; a transformer-based mode activates for ambiguous cases where vocabulary is too specialised for keyword matching.

Summaries

Three levels designed for different reading contexts: TL;DR (2–3 sentences, fast triage), executive (structured paragraph, decision-making), detailed (full breakdown of method, results and contribution). Generated via GPT-4o with document context injected.

Recommendations

OpenAI embeddings represent each viewed document as a semantic vector. The engine queries the FAISS index for k-nearest neighbours and ranks results by a combined score of content proximity and metadata alignment (domain, methodology, institution). Goes beyond keyword overlap to find structurally similar work.
